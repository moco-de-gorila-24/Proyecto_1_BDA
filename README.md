# Proyecto 1 Bases de datos avanzadas
Este es un sistema gestor de una veterinaria, implementando Java como lenguaje principal junto con jdbc y mysql como motor de base de datos 

## Instalación
Requisitos previos:
-Java 21+ / MySql 8.3.0+ 

```Administrador de archivos
Descomprimir el proyecto comprimido
Eliminar las carpetas de compilacion de las IDEs ejemplo: .idea, target, build etc.
```

## Uso

```Netbeans/Intellij
Iniciar la clase main desde la IDE
```

## Configuración
```Credenciales
cambiar credenciales de la clase: Conexion
```
